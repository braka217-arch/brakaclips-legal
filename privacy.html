Política de Privacidad

brakaclips · Última actualización: 16 de agosto de 2026

1. Alcance

brakaclips es una herramienta de uso personal que opera únicamente sobre la cuenta de TikTok de su autor (el "operador"). No tiene usuarios además del operador, no ofrece registro y no recopila datos de ninguna otra persona.

2. Qué datos se manejan

Cuando el operador autoriza la herramienta mediante TikTok Login Kit, TikTok entrega:

  • Un token de acceso y un token de refresco — credenciales técnicas que permiten subir videos a la cuenta autorizada.
  • Información básica de perfil (permiso user.info.basic): identificador abierto, nombre visible y foto de perfil de la propia cuenta del operador.

Además, la herramienta procesa los archivos de video que el operador elige subir.

3. Cómo se usan

Los tokens se usan exclusivamente para autenticar las llamadas a la Content Posting API de TikTok y subir videos como borrador. La información de perfil se usa solo para confirmar qué cuenta está conectada. Los videos se transmiten a TikTok y no se conservan en ningún servidor.

4. Dónde se guardan

La herramienta se ejecuta localmente en la computadora del operador. Los tokens se almacenan en un archivo local en esa máquina. No existe servidor propio, base de datos remota ni servicio en la nube operado por brakaclips. Ningún dato se transmite a terceros distintos de TikTok.

5. Con quién se comparten

Con nadie. Los datos no se venden, alquilan, ceden ni comparten. La única transmisión de datos es hacia las APIs oficiales de TikTok, sujetas a la Política de Privacidad de TikTok.

6. Retención y eliminación

Los tokens se conservan mientras la herramienta esté en uso y se eliminan borrando el archivo local de credenciales. El operador puede revocar el acceso en cualquier momento desde TikTok → Perfil → Configuración y privacidad → Seguridad y permisos → Administrar permisos de apps, lo que invalida los tokens de inmediato.

7. Menores

La herramienta no está dirigida a menores de edad y no recopila datos de menores.

8. Cookies y analítica

Este sitio es estático. No usa cookies, ni analítica, ni rastreadores de terceros.

9. Cambios

Esta política puede actualizarse; la versión vigente es la publicada en esta página.

Privacy Policy

brakaclips · Last updated: August 16, 2026

1. Scope

brakaclips is a personal-use tool that operates solely on its author's ("the operator's") own TikTok account. It has no users other than the operator, offers no sign-up, and collects no data from any other person.

2. Data handled

When the operator authorizes the tool via TikTok Login Kit, TikTok provides an access token and a refresh token (technical credentials used to upload videos), and basic profile information under the user.info.basic scope (open ID, display name, avatar) for the operator's own account. The tool also processes the video files the operator chooses to upload.

3. How data is used

Tokens are used only to authenticate calls to TikTok's Content Posting API and upload videos as drafts. Profile information is used only to confirm which account is connected. Videos are transmitted to TikTok and are not retained on any server.

4. Where data is stored

The tool runs locally on the operator's computer. Tokens are stored in a local file on that machine. There is no backend server, remote database, or cloud service operated by brakaclips. No data is transmitted to any third party other than TikTok.

5. Sharing

None. Data is not sold, rented, or shared. The only transmission is to TikTok's official APIs, governed by TikTok's own Privacy Policy.

6. Retention and deletion

Tokens are retained while the tool is in use and are deleted by removing the local credentials file. The operator can revoke access at any time in TikTok under Settings and privacy → Security and permissions → Manage app permissions, which invalidates the tokens immediately.

7. Children

The tool is not directed at minors and collects no data from minors.

8. Cookies and analytics

This site is static. It uses no cookies, analytics, or third-party trackers.

This policy may be updated; the version published on this page is the one in force.
